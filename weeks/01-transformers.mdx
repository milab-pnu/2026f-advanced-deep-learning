## 1. 순차 모델의 벽

2017년 이전의 기계번역(neural machine translation)은 대부분 **RNN 기반 encoder-decoder**
구조였다. encoder 가 source 문장을 왼쪽에서 오른쪽으로 한 토큰씩 읽어 hidden state
$h_t = f(h_{t-1}, x_t)$ 를 갱신하고, decoder 가 그 정보를 받아 target 문장을 한 토큰씩
생성한다. 여기에 attention 을 얹어 decoder 가 매 스텝 source 의 특정 위치를 "돌아보게"
한 것이 Bahdanau 등의 기여였다.<Cite n={2} />

이 방식에는 두 가지 구조적 한계가 있다.

<Callout type="warning">
**순차 계산.** $h_t$ 를 구하려면 $h_{t-1}$ 이 있어야 한다. 길이 $n$ 문장의 forward
pass 는 $O(n)$ 번의 순차 스텝을 강제하고, 이 사슬은 병렬화할 수 없다. GPU 는 놀고
시퀀스가 길수록 학습이 느려진다.
</Callout>

<Callout type="warning">
**장거리 의존성.** 문장 첫 단어의 정보가 마지막 단어에 닿으려면 $n$개의 RNN 스텝을
통과해야 한다. 경로가 길수록 gradient 가 소실·폭발하기 쉽고, 멀리 떨어진 단어 사이의
관계를 학습하기 어렵다.
</Callout>

Transformer 의 출발점은 이것이다: **recurrence 를 완전히 버리고, 시퀀스 안의 모든 위치
쌍을 attention 한 번으로 직접 연결하면 어떨까?** 그러면 위치 $i$ 와 $j$ 사이의 경로
길이는 항상 1이고, 한 레이어의 계산은 전부 병렬로 돌릴 수 있다.

## 2. 큰 그림

Transformer 도 encoder-decoder 다. 다만 두 스택 모두 recurrence 나 convolution 없이
**attention 과 position-wise feed-forward 두 종류의 연산만** 쌓는다.

- **Encoder**: 동일한 레이어 $N=6$ 개. 각 레이어는 (1) multi-head **self-attention** +
  (2) position-wise **feed-forward network** 두 sub-layer 로 구성. source 시퀀스를 받아
  같은 길이의 표현 시퀀스 $z_1, \dots, z_n$ 을 출력한다.
- **Decoder**: 역시 $N=6$ 개 레이어. encoder 레이어에 sub-layer 하나가 추가된다 —
  encoder 출력을 향한 **cross-attention**. 또한 decoder 의 self-attention 은 미래
  토큰을 못 보도록 **masking** 된다(아래 5절).
- 모든 sub-layer 출력에는 **residual connection** 과 **layer normalization** 이 붙는다.
- 임베딩 차원은 전 구간에서 $d_{\text{model}} = 512$ 로 고정된다 (residual 을 더하려면
  차원이 같아야 한다).

<Sidenote>
"동일한 레이어를 쌓는다"는 것은 구조가 같다는 뜻이지 가중치를 공유한다는 뜻이 아니다.
6개 레이어는 각자 별도의 파라미터를 가진다.
</Sidenote>

이제 핵심 부품인 attention 부터 본다.

## 3. Attention 이라는 연산

### 3.1 Query, Key, Value

attention 은 **딕셔너리 조회(soft dictionary lookup)** 로 이해하는 것이 가장 빠르다.

- 우리가 찾고자 하는 것을 나타내는 벡터가 **query** $q$.
- 각 저장 항목에는 색인 역할을 하는 **key** $k_j$ 와, 실제 내용인 **value** $v_j$ 가 있다.
- 조회는 $q$ 와 각 $k_j$ 의 유사도를 재서, 그 유사도를 가중치로 $v_j$ 들을 섞어 돌려준다.

하드 딕셔너리라면 "정확히 일치하는 key 하나의 value 만 반환"하지만, attention 은 유사도를
softmax 로 정규화해 **모든 value 의 가중 평균**을 반환한다. 그래서 미분 가능하고 학습된다.

<Callout type="intuition">
"문장에서 대명사 *it* 이 무엇을 가리키는가"를 풀 때, *it* 의 query 가 앞쪽 명사들의
key 와 높은 내적을 갖도록 학습되면, *it* 의 새 표현은 그 명사의 value 를 많이 담게 된다.
attention 은 이런 "어디를 봐야 하는가"를 데이터로부터 배운다.
</Callout>

### 3.2 Scaled Dot-Product Attention

유사도로는 **내적(dot product)** 을 쓴다. query 하나 $q \in \mathbb{R}^{d_k}$ 와
key 행렬 $K \in \mathbb{R}^{m \times d_k}$, value 행렬 $V \in \mathbb{R}^{m \times d_v}$
에 대해:

$$
\mathrm{Attention}(q, K, V) = \sum_{j=1}^{m} \underbrace{\frac{\exp(q \cdot k_j / \sqrt{d_k})}{\sum_{l} \exp(q \cdot k_l / \sqrt{d_k})}}_{\text{attention weight } \alpha_j} \, v_j
$$

실제로는 query 도 한꺼번에 처리한다. $n$개의 query 를 행으로 쌓은
$Q \in \mathbb{R}^{n \times d_k}$ 에 대해 전체 연산은 행렬 두 번의 곱과 한 번의
softmax 로 끝난다:

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left( \frac{Q K^{\top}}{\sqrt{d_k}} \right) V
$$

여기서 softmax 는 행 단위로 적용된다. 결과는 $n \times d_v$ 행렬이고, $i$번째 행은
$i$번째 query 에 대한 value 들의 가중 평균이다.

### 3.3 왜 √dₖ 로 나누는가

이 스케일링은 논문의 작지만 중요한 디테일이다.

<Callout type="example">
$q$ 와 $k$ 의 각 성분이 평균 0, 분산 1인 독립 확률변수라고 하자. 그러면 내적
$q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 는 평균 0, 분산 $d_k$ 다. 즉 $d_k$ 가 커지면
내적의 전형적 크기는 $\sqrt{d_k}$ 에 비례해 커진다.
</Callout>

내적 값이 크면 softmax 입력의 한 성분이 나머지를 압도해, 출력이 거의 one-hot 에
가까워진다. 이 영역에서 softmax 의 Jacobian 은 거의 0이라 **gradient 가 사라진다**.
스케일을 $1/\sqrt{d_k}$ 로 잡으면 내적의 분산이 다시 1 근처로 돌아와 softmax 가
민감한 영역에서 동작한다.

<Details summary="softmax 포화와 gradient 소실 — 조금 더 정확히">
$p = \mathrm{softmax}(s)$ 일 때 $\dfrac{\partial p_i}{\partial s_j} = p_i(\delta_{ij} - p_j)$
이다. 어떤 $p_k \to 1$ 이면 모든 $j$ 에 대해 $\dfrac{\partial p_k}{\partial s_j} \to 0$
이고, 다른 성분들의 미분도 전부 0으로 수렴한다. 따라서 attention score 가
과도하게 크면 상류로 전달되는 gradient 가 거의 없어져, attention 패턴이 초기값 근처에
얼어붙는다. $\sqrt{d_k}$ 스케일은 학습 초기에 score 분포를 표준정규 근처로 유지해
이 포화를 막는 역할을 한다. 실전에서는 이 스케일을 빼면 큰 $d_k$ 에서 학습이 눈에
띄게 불안정해진다.
</Details>

## 4. Multi-Head Attention

$d_{\text{model}}$ 차원 공간에서 attention 을 한 번만 수행하면, 모델은 "한 종류의
관계"만 포착하도록 강제된다. 대신 표현을 여러 개의 저차원 부분공간으로 나눠, 각
부분공간에서 **독립적으로 attention 을 병렬 수행**한 뒤 결과를 합친다.

$h = 8$ 개의 head 각각에 대해 학습된 projection 행렬
$W_i^Q, W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$,
$W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$ 로 입력을 투영하고:

$$
\mathrm{head}_i = \mathrm{Attention}(Q W_i^Q,\; K W_i^K,\; V W_i^V)
$$

$$
\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\mathrm{head}_1, \dots, \mathrm{head}_h)\, W^O
$$

논문은 $d_k = d_v = d_{\text{model}} / h = 64$ 로 잡는다. 이렇게 하면 head 를 나눠도
전체 연산량이 single-head full-dimension attention 과 비슷하다.

<Callout type="intuition">
서로 다른 head 는 서로 다른 관계를 배우는 경향이 있다 — 어떤 head 는 바로 옆 단어에,
어떤 head 는 구문상 지배소(head word)에, 어떤 head 는 문장 전체에 고르게 주의를
분산한다. Multi-head 는 "여러 관점에서 동시에 문장을 읽는" 장치라고 볼 수 있다.
</Callout>

## 5. Transformer 안의 세 가지 Attention

같은 multi-head attention 블록이 위치에 따라 세 가지 역할을 한다.

1. **Encoder self-attention.** $Q, K, V$ 가 모두 직전 encoder 레이어의 출력. 각 위치가
   source 문장의 모든 위치를 본다. 마스킹 없음.
2. **Decoder masked self-attention.** $Q, K, V$ 가 모두 직전 decoder 레이어의 출력.
   단, 위치 $i$ 는 $j \le i$ 인 위치만 볼 수 있다. 미래 토큰을 보면 학습 시 정답을
   컨닝하게 되므로, softmax 이전 score 행렬에서 $j > i$ 인 원소를 $-\infty$ 로
   채운다(look-ahead mask).
3. **Encoder-decoder (cross) attention.** $Q$ 는 직전 decoder 레이어에서, $K, V$ 는
   **encoder 최종 출력**에서 온다. decoder 의 각 위치가 source 문장 전체를 참조한다 —
   기존 seq2seq attention 이 하던 일이 바로 이것이다.

<Callout type="note">
inference 때 decoder 는 여전히 토큰을 하나씩 autoregressive 하게 생성한다. Transformer
가 없앤 것은 **학습 시**의 순차 사슬이다 — teacher forcing 으로 정답 시퀀스를 통째로
넣고 masked self-attention 으로 한 번에 병렬 학습한다.
</Callout>

## 6. Positional Encoding

attention 은 집합 연산이다 — 입력 순서를 바꾸면 출력도 그대로 순서만 바뀔 뿐,
"몇 번째 위치인가"라는 정보가 없다. recurrence 를 버렸으니 위치 정보를 명시적으로
주입해야 한다.

논문은 학습 파라미터 없이 고정된 **정현파(sinusoidal) positional encoding** 을 쓴다.
위치 $pos$, 차원 인덱스 $i$ 에 대해:

$$
PE_{(pos,\, 2i)} = \sin\!\left( \frac{pos}{10000^{2i/d_{\text{model}}}} \right), \qquad
PE_{(pos,\, 2i+1)} = \cos\!\left( \frac{pos}{10000^{2i/d_{\text{model}}}} \right)
$$

이 벡터를 토큰 임베딩에 **더한다**.

<Callout type="intuition">
차원마다 파장이 기하급수적으로 달라지는 정현파를 겹쳐놓은 것이다. 낮은 차원은
빠르게 진동(가까운 위치 구분), 높은 차원은 천천히 진동(멀리 떨어진 위치 구분).
게다가 삼각함수 덧셈정리에 의해 $PE_{pos+k}$ 는 $PE_{pos}$ 의 **선형변환**으로
표현된다 — 모델이 "상대 위치 $k$ 만큼 이동"을 선형 연산으로 배우기 쉽다.
</Callout>

<Sidenote>
논문은 학습되는 positional embedding 도 실험했고 성능은 거의 같았다. 정현파를 택한
이유는 학습 때 본 것보다 긴 시퀀스로도 외삽(extrapolate)될 가능성 때문이다.
</Sidenote>

## 7. Position-wise Feed-Forward Network

각 attention sub-layer 뒤에는 **위치마다 독립적으로** 적용되는 2층 MLP 가 붙는다.

$$
\mathrm{FFN}(x) = \max(0,\; x W_1 + b_1)\, W_2 + b_2
$$

$W_1 \in \mathbb{R}^{d_{\text{model}} \times d_{ff}}$,
$W_2 \in \mathbb{R}^{d_{ff} \times d_{\text{model}}}$ 이고 논문은 $d_{ff} = 2048$ 을 쓴다
(즉 안쪽에서 4배로 넓혔다가 다시 좁힌다). 같은 레이어 안에서는 모든 위치가 같은
$W_1, W_2$ 를 공유하지만, 레이어마다는 다르다.

<Callout type="note">
attention 이 "위치들 사이에서 정보를 섞는" 연산이라면, FFN 은 "각 위치의 표현을
비선형으로 가공하는" 연산이다. 두 연산이 번갈아 쌓이면서 mixing 과 transformation 을
반복한다. FFN 은 $1 \times 1$ convolution 두 개로 봐도 동일하다.
</Callout>

## 8. Residual Connection 과 Layer Normalization

모든 sub-layer 는 다음 형태로 감싸진다:

$$
\mathrm{output} = \mathrm{LayerNorm}\big( x + \mathrm{Sublayer}(x) \big)
$$

- **Residual connection** $x + \mathrm{Sublayer}(x)$ 는 6개 레이어를 관통하는 짧은
  gradient 경로를 만들어 깊은 스택의 학습을 가능하게 한다. residual 을 더하려면
  입력과 출력 차원이 같아야 하므로 전 구간 $d_{\text{model}} = 512$ 다.
- **Layer normalization**<Cite n={3} /> 은 각 위치의 특성벡터를 그 벡터 안에서
  평균 0, 분산 1로 정규화한다(batch 축이 아니라 feature 축). 배치 크기·시퀀스 길이에
  무관하게 안정적이라 시퀀스 모델에 잘 맞는다.

## 9. 전체 조립

한 **encoder 레이어**:

```
x1 = LayerNorm(x  + MultiHeadSelfAttention(x))
x2 = LayerNorm(x1 + FFN(x1))
```

한 **decoder 레이어**:

```
y1 = LayerNorm(y  + MaskedMultiHeadSelfAttention(y))
y2 = LayerNorm(y1 + CrossAttention(query=y1, key=value=encoderOutput))
y3 = LayerNorm(y2 + FFN(y2))
```

전체 forward:

1. source 토큰 → 임베딩 + positional encoding → encoder 6레이어 → $z$ (source 표현)
2. target 토큰(shift right) → 임베딩 + positional encoding → decoder 6레이어(매
   레이어에서 $z$ 를 cross-attention 으로 참조)
3. decoder 출력 → 임베딩 행렬과 묶인(tied) linear → softmax → 다음 토큰 분포

<Sidenote>
입력·출력 임베딩 행렬과 최종 pre-softmax linear 는 같은 가중치를 공유한다(weight
tying). 파라미터를 아끼고 대체로 성능도 좋아진다.
</Sidenote>

## 10. 왜 되는가 — 복잡도와 경로 길이

논문의 핵심 논거는 세 축의 비교표다 ($n$ = 시퀀스 길이, $d$ = 표현 차원,
$k$ = convolution 커널 크기).

| 레이어 종류 | 레이어당 복잡도 | 순차 연산 | 최대 경로 길이 |
|---|---|---|---|
| Self-Attention | $O(n^2 \cdot d)$ | $O(1)$ | $O(1)$ |
| Recurrent | $O(n \cdot d^2)$ | $O(n)$ | $O(n)$ |
| Convolutional | $O(k \cdot n \cdot d^2)$ | $O(1)$ | $O(\log_k n)$ |
| Self-Attention (윈도우 $r$) | $O(r \cdot n \cdot d)$ | $O(1)$ | $O(n/r)$ |

읽는 법:

- **순차 연산 $O(1)$**: self-attention 한 레이어는 시퀀스 길이와 무관하게 상수 번의
  행렬곱으로 끝난다 → 완전 병렬.
- **최대 경로 길이 $O(1)$**: 어떤 두 위치든 한 번의 attention 으로 직접 연결 →
  장거리 의존성 학습에 유리.
- **비용**: 대신 레이어당 계산이 $n^2$ 에 비례한다. $n < d$ 인 전형적 문장 번역
  ($n \approx 40$, $d = 512$)에서는 recurrent 보다 오히려 싸지만, 문서 단위로 $n$ 이
  커지면 이 $n^2$ 항이 Transformer 후속 연구의 최대 관심사가 된다.

<Callout type="intuition">
Transformer 의 거래는 이렇다: **순차 깊이(느림, 학습 난이도)를 시퀀스 길이 제곱의
계산량(병렬화 가능, 메모리)으로 바꿨다.** GPU 시대에는 남는 장사였다.
</Callout>

## 11. 학습 레시피

아키텍처만큼이나 재현에 중요한 디테일들.

- **Optimizer**: Adam, $\beta_1 = 0.9$, $\beta_2 = 0.98$, $\epsilon = 10^{-9}$.
- **Learning rate schedule**: warmup 후 역제곱근 감쇠.

  $$
  lr = d_{\text{model}}^{-0.5} \cdot \min\!\left( step^{-0.5},\; step \cdot warmup^{-1.5} \right)
  $$

  $warmup = 4000$ steps. 초반에는 선형 증가, 이후 $step^{-0.5}$ 로 감소.
- **Regularization**: 모든 sub-layer 출력과 임베딩 합에 dropout $P_{drop} = 0.1$;
  label smoothing $\epsilon_{ls} = 0.1$ (perplexity 는 나빠지지만 BLEU·정확도는 개선).
- **Hardware / 시간**: 8× NVIDIA P100. base 모델 100k steps ≈ 12시간, big 모델
  300k steps ≈ 3.5일.
- **데이터**: WMT 2014 English–German (약 4.5M 문장쌍, byte-pair encoding 37k),
  English–French (약 36M 문장쌍).

<Callout type="warning">
warmup 없는 Adam 은 Transformer 학습 초기에 자주 발산한다. LR schedule 은 선택이
아니라 사실상 필수 부품이다. 이후 연구들이 pre-LN 구조, RAdam 등으로 이 민감도를
완화한다.
</Callout>

## 12. 결과와 그 이후

- **WMT 2014 EN→DE**: big 모델 28.4 BLEU — 당시 앙상블 포함 최고 기록을 2 BLEU 이상
  경신.
- **WMT 2014 EN→FR**: big 모델 41.8 BLEU — 기존 SOTA 를, 학습 비용의 일부만으로 갱신.
- **English constituency parsing** 에서도 잘 동작 — 번역 전용 트릭이 아니라 범용
  시퀀스 모델임을 시사.

Transformer 는 곧 번역을 넘어 확장된다. encoder 만 떼어내 양방향 마스킹 언어모델로
사전학습한 것이 **BERT**<Cite n={4} />, decoder 만 떼어내 autoregressive 언어모델로
키운 것이 **GPT** 계열이다. 오늘날의 대규모 언어모델은 사실상 전부 이 노트에서 조립한
블록의 스케일업이다.

## 13. 정리

- Transformer 는 recurrence·convolution 없이 **attention + position-wise FFN** 만으로
  seq2seq 를 수행한다.
- **Scaled dot-product attention** 은 query–key 내적을 $\sqrt{d_k}$ 로 스케일한 뒤
  softmax 가중 평균으로 value 를 섞는다.
- **Multi-head** 는 여러 부분공간에서 attention 을 병렬 수행해 다양한 관계를 포착한다.
- **Positional encoding** 이 순서 정보를, **residual + LayerNorm** 이 깊은 스택의
  학습 가능성을, **warmup LR schedule** 이 초기 안정성을 담당한다.
- 대가로 레이어당 계산이 $O(n^2 d)$ 지만, 순차 깊이 $O(1)$·경로 길이 $O(1)$ 을 얻어
  병렬 학습과 장거리 의존성에서 크게 앞선다.

다음 노트에서 이 구조를 PyTorch 로 처음부터 구현하고, 작은 번역 태스크에서 학습시켜
본다.
