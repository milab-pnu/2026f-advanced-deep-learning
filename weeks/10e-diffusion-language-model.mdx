일반적인 autoregressive(AR) 언어 모델은 이미 나온 token을 바탕으로 다음 token을 하나씩 생성한다.
Diffusion language model은 텍스트를 손상시키는 과정과 이를 복원하는 과정을 정의해 생성하는 다른 접근이다.[^survey]
텍스트를 연속 벡터로 다루는 방법과 이산적인 token을 mask로 바꾸는 방법을 비교한 뒤, mask를 이용한 학습과 생성을 살펴본다.

## 1. 텍스트의 생성과 손상

### 1-1. Autoregressive 생성

Token sequence $x_1,\ldots,x_L$에 대한 AR 모델의 결합확률은 다음과 같이 분해된다.

$$
p(x_1,\ldots,x_L)=\prod_{i=1}^{L}p(x_i\mid x_1,\ldots,x_{i-1}).
$$

생성할 때 첫 token을 뽑고 그 결과를 조건으로 두 번째 token을 뽑는다.
이 방식은 명확한 확률 분해를 제공하지만, 앞의 결과를 알기 전에는 일반적인 순차 decoding에서 다음 token을 확정할 수 없다.
학습 시에는 정답 sequence를 이미 알고 있으므로 causal attention을 사용해 여러 위치의 예측을 병렬로 계산할 수 있다.
학습의 병렬성과 생성의 순차성을 구분해야 한다.

### 1-2. Continuous와 discrete 상태

Diffusion에서 continuous와 discrete는 우선 모델이 손상시키는 **상태의 종류**를 말한다.
이미지 DDPM은 실수 벡터에 Gaussian noise를 더하므로 continuous-state diffusion이다.
시간을 여러 개의 정수 단계로 나눴더라도 상태의 값은 연속이다.
반면 discrete-state diffusion은 가능한 상태와 그 상태 사이의 전이 확률을 정의한다.[^d3pm]
시간 자체를 연속으로 나타낼 수 있는지와 상태가 연속인지도 별개의 선택이다.

텍스트에서도 두 접근이 모두 가능하다.[^diffusion-lm]

| 구분 | Continuous-state 언어 diffusion | Discrete-state 언어 diffusion |
|---|---|---|
| 모델이 다루는 상태 | token의 연속 embedding 벡터 | token이나 mask 같은 이산 기호 |
| Forward 손상 | 예를 들어 벡터에 Gaussian noise 추가 | 예를 들어 token을 mask로 대체 |
| 생성 결과 | 연속 벡터를 token으로 변환 | token 확률을 예측해 기호를 선택 |
| 예 | Diffusion-LM | D3PM, LLaDA |

Continuous 접근에서 `고양이` token을 embedding 벡터로 바꾼 뒤 벡터에 noise를 더하면, 중간 상태는 어느 단어 하나의 ID가 아니라 실수 벡터다.
생성의 마지막에는 각 위치의 벡터를 어휘의 token으로 읽어 내야 한다.
이 변환을 어떻게 학습하고 처리할지가 별도의 설계 문제다.
Discrete 접근은 ID 숫자 자체에 산술적으로 noise를 더하지 않고 기호가 다른 상태로 바뀔 확률을 정한다.

Continuous 언어 diffusion의 한 경로를 따라가 보자.
학습할 때 token sequence를 embedding sequence $e(x)$로 바꾸고, 각 위치의 벡터에 Gaussian noise를 섞어 모델에 준다.
모델은 noisy vector에서 깨끗한 embedding에 관한 정보를 예측하도록 학습한다.
생성 때는 연속 noise 벡터들에서 출발해 반복적으로 갱신한 뒤, 마지막 벡터들을 어휘의 기호로 바꾸는 decoding 단계가 필요하다.
예를 들어 각 위치의 최종 벡터와 token embedding들의 거리를 비교하는 rounding을 사용할 수 있다.[^diffusion-lm]
두 token의 embedding이 가까우면 작은 벡터 차이가 다른 token 선택으로 이어질 수도 있다.
이 과정은 token ID에 noise를 더하는 것과 다르다.

<Figure src="https://tuananhbui89.github.io/assets/img/diffusion-foundation/diffusion-lm-overview.png" alt="연속 Gaussian noise 벡터가 여러 denoising 단계를 거쳐 단어 벡터가 되고 텍스트로 바뀐다. 아래에는 문장 구조 조건을 제공하는 classifier가 연결되어 있다." caption="연속 벡터에서 텍스트를 생성하는 Diffusion-LM. 위쪽은 noise에서 단어 벡터로 이동하는 경로이고, 아래 classifier는 원하는 문장 구조를 추가로 반영하는 선택적 제어다." source="Li et al. 그림에서 $x_T,\ldots,x_0$는 연속 벡터이고 $w$는 최종 텍스트다.
아래의 classifier는 원하는 문장 구조를 반영하기 위해 추가한 예시이며 모든 연속 diffusion 언어 모델에 필요한 구성은 아니다.

### 1-3. Discrete diffusion

이산 diffusion에서 mask는 여러 가능한 손상 방식 중 하나다.
한 번 가린 위치가 이후 forward 단계에서도 계속 mask로 남도록 전이 확률을 정할 수 있다.

예를 들어 원래 문장이 `나는 오늘 학교에 간다`라고 하자.
Forward 과정에서 선택된 token을 `[MASK]`로 바꾸면 다음처럼 정보를 점차 잃게 만들 수 있다.

| 단계 | 상태 |
|---|---|
| 원본 | 나는 오늘 학교에 간다 |
| 일부 손상 | 나는 [MASK] 학교에 [MASK] |
| 완전 손상 | [MASK] [MASK] [MASK] [MASK] |

실제 token은 단어나 띄어쓰기 단위와 일치하지 않을 수 있다.
이 표는 이해를 위한 단순화된 예다.
한 번 mask가 된 위치가 계속 mask로 남는 과정을 absorbing-mask 과정이라 한다.
손상 확률은 시간에 따라 정해지며, 충분히 손상된 상태에서 역방향으로 token을 복원하는 생성 과정을 설계한다.

<Callout type="example">
어떤 위치가 아직 `학교에`이고 다음 단계에서 mask될 확률이 0.2라면, 그 위치는 확률 0.8로 `학교에`를 유지하고 확률 0.2로 `[MASK]`가 된다.
이미 `[MASK]`인 위치는 확률 1로 `[MASK]`에 머문다.
이처럼 연속 noise 대신 기호 사이의 전이 확률을 정한 것이 discrete forward 과정이다.
수치는 개념을 위한 예이며 LLaDA의 특정 단계 설정을 뜻하지 않는다.
</Callout>

전이 확률을 행렬로 쓰면 mask 외의 손상 방식도 같은 틀에서 나타낼 수 있다.
가능한 상태를 `A`, `B`, `M` 세 가지로 줄이고, 행은 이전 상태, 열은 다음 상태라고 하자.

$$
Q=\begin{pmatrix}
0.8&0&0.2\\
0&0.8&0.2\\
0&0&1
\end{pmatrix}.
$$

첫 행은 `A`가 `A`에 머물 확률 0.8과 `M`으로 바뀔 확률 0.2를 나타낸다.
마지막 행에서는 mask가 mask로 남을 확률이 1이다.
같은 $Q$를 두 단계 연속 쓰면 처음 `A`였던 위치가 여전히 `A`일 확률은 $0.8^2=0.64$다.
서로 다른 단계의 전이 행렬을 곱하면 그 단계들을 거친 누적 전이를 얻는다.
D3PM은 이처럼 전이 행렬을 설계해 mask뿐 아니라 다른 이산 손상도 표현한다.[^d3pm]

## 2. Masked diffusion의 학습과 생성

### 2-1. 학습 목표

LLaDA는 시간에 따른 masking으로 학습 데이터를 손상시키고 Transformer가 가려진 token을 예측하도록 학습한다.[^llada]
원본 sequence와 mask 위치를 알고 있으므로 각 위치의 정답 token에 대한 확률을 높일 수 있다.
모델은 각기 다른 비율로 가려진 입력을 경험하고, 남아 있는 양쪽 문맥을 활용해 빠진 token의 분포를 예측한다.
LLaDA의 목적함수는 시간에 따른 가중치와 likelihood bound에 연결되므로 단순히 하나의 고정 mask 비율만 쓰는 분류 문제로 축약하지 않는다.

LLaDA의 한 설정에서는 $t$를 0과 1 사이에서 균일하게 뽑고 각 token을 독립적으로 확률 $t$로 mask한다.
원래 sequence를 $x_0$, 손상된 sequence를 $x_t$, mask token을 $\mathrm{M}$이라 하면 손실은 다음과 같다.

$$
L(\theta)=-\mathbb{E}_{t,x_0,x_t}\left[\frac{1}{t}\sum_{i=1}^{L}
\mathbf{1}[x_t^i=\mathrm{M}]\log p_\theta(x_0^i\mid x_t)\right].
$$

지시 함수 $\mathbf{1}[\cdot]$는 해당 위치가 mask이면 1, 아니면 0이므로 가려진 위치에서만 손실을 계산한다.
예를 들어 네 token 중 둘만 가려졌다면 두 정답의 log probability가 합에 들어간다.
$1/t$는 noise 수준에 따라 손실에 주는 가중치이며, $t$는 mask 비율을 정하는 변수다.
이 모델의 특정 parameterization에서는 모델에 $t$를 별도 입력으로 주지 않아도 된다.

BERT도 mask된 token을 예측하지만, 그런 학습 목표를 가진 모델이면 모두 곧바로 같은 생성 모델이 되는 것은 아니다.
Diffusion 언어 모델에는 손상 확률, 각 noise 수준의 학습, 초기 상태에서 시작해 여러 단계에 걸쳐 token을 복원하는 sampling 절차가 함께 필요하다.

### 2-2. 역방향 생성 예시

조건으로 주어진 prompt를 유지하고 생성할 영역을 mask로 시작한다고 하자.
한 번의 모델 호출은 mask된 여러 위치에 대한 후보 token 분포를 만들 수 있다.
Sampler는 그 예측과 정해진 정책에 따라 일부 위치를 채우고, 남은 mask에 대해 다시 모델을 호출한다.

| 단계 | 생성 영역의 예시 |
|---|---|
| 시작 | `[MASK] [MASK] [MASK] [MASK]` |
| 중간 | `나는 [MASK] 학교에 [MASK]` |
| 종료 | `나는 오늘 학교에 간다` |

중간 단계에서 채울 위치는 왼쪽부터일 필요가 없다.
LLaDA는 낮은 신뢰도의 후보를 다시 mask로 남기는 방식 등을 분석한다.
구체적으로 이미 확정한 token을 수정할 수 있는지, 위치를 어떻게 선택하는지는 sampler에 따라 달라진다.
위 예의 문장은 가능한 한 경로를 설명할 뿐, 모델이 항상 같은 순서로 복원한다는 뜻은 아니다.

### 2-3. Prompt와 출력 길이

Instruction을 따르는 모델에서는 prompt를 조건으로 보존하고 응답에 해당하는 부분을 손상·복원하는 방식으로 학습과 생성을 구성할 수 있다.
생성할 영역의 길이를 미리 정해 두는 방식에서는 그 길이 선택도 결과에 영향을 준다.
길이 처리, 종료 token, 여러 블록에 걸친 생성은 구현별로 다르므로 모든 diffusion 언어 모델이 같은 방식으로 응답 길이를 정한다고 보면 안 된다.

LLaDA의 supervised fine-tuning(SFT)은 prompt를 보존한 채 응답 부분만 무작위로 mask한다.
이와 달리 improved LLaDA(iLLaDA)는 prompt와 응답, 종료 token을 이어 붙인 학습 sequence 전체에 masking을 적용한다.[^illada]
두 모델 모두 masked diffusion 손실을 쓰지만, 어떤 token을 학습에서 가릴 수 있는지는 다르다.

### 2-4. iLLaDA의 학습과 가변 길이 생성

iLLaDA는 LLaDA와 같은 masked diffusion 목표를 유지하면서 8B 양방향 Transformer를 처음부터 학습한 모델이다.[^illada]
원논문은 pre-training에 12조 token을 사용했고, 약 250억 token의 instruction corpus로 12 epoch SFT했다고 보고한다.
LLaDA에서 사용한 multi-head attention 대신 grouped-query attention(GQA)을 쓰고 입력 embedding과 출력 head의 weight를 공유한다.
GQA의 cache 메모리 이점은 해당 상태를 재사용하는 cache 방식이 적용되는 경우에 관한 것으로, diffusion에서는 각 단계마다 상태가 바뀌므로 cache 재사용 정책을 따로 고려해야 한다.

생성할 때 iLLaDA는 prompt 뒤에 일정 크기의 mask block을 붙이고, 여러 denoising 단계에 걸쳐 신뢰도가 높은 예측을 채운다.
Block 안에서 종료 token이 나오면 멈추고, 그렇지 않으면 새 mask block을 붙여 계속한다.
예를 들어 block 길이가 4라면 첫 네 위치를 복원한 뒤 필요한 경우 다음 네 위치를 생성한다.
이 예의 길이는 설명용이며, 원논문은 task별로 서로 다른 block 길이와 최대 길이를 사용한다.
Block 안의 token은 병렬로 예측할 수 있지만 block 사이와 denoising 단계는 순차적으로 진행된다.

가상 예시로 prompt가 `오늘 날씨는`이고 block 길이가 4라고 하자.
첫 입력은 prompt 뒤에 `[MASK] [MASK] [MASK] [MASK]`를 둔다.
모델이 네 위치의 후보를 한 번에 예측한 뒤, sampler가 자신 있는 위치부터 채우고 나머지를 다시 예측한다.
첫 block이 `맑고 바람이 약합니다 .`처럼 채워졌는데 종료 token이 없다면 이를 문맥으로 남기고 새 mask block을 뒤에 붙인다.
다음 block에서 종료 token이 생성되면 그 위치에서 멈춘다.
이는 작동 순서를 보여 주는 가상 예시이고, 문장 조각이 실제 tokenizer에서 네 token이라는 뜻은 아니다.

객관식 평가에서는 후보 답안의 token을 높은 신뢰도 순으로 드러내며 점수를 계산하는 방법도 제안한다.
이 confidence score는 후보를 비교하기 위한 점수이지 정확한 sequence likelihood는 아니다.
원논문의 성능 향상은 데이터 규모와 학습 방식, 평가 방법이 함께 달라진 결과이므로 한 가지 변경만의 효과로 단정하지 않는다.

## 3. AR 모델과의 비교

| 관점 | Autoregressive 모델 | Masked diffusion 언어 모델의 대표적 방식 |
|---|---|---|
| 학습 | 앞 문맥에서 다음 token 예측 | 다양한 손상 수준에서 가려진 token 예측 |
| 생성 | 앞에서 뒤로 token을 차례로 선택 | mask된 여러 위치를 반복적으로 예측하고 채움 |
| 문맥 | 생성 시 이미 나온 앞쪽 문맥 | 현재 남아 있거나 복원된 양쪽 문맥 |
| 계산 | token 생성마다 모델 호출 | 여러 token을 병렬 예측하되 여러 denoising 단계 필요 |
| 활용 | 자연스러운 왼쪽에서 오른쪽 이어 쓰기 | infilling과 유연한 위치 선택 가능 |

병렬로 여러 위치를 예측할 수 있다는 점은 잠재적 이점이다.
하지만 전체 sequence를 여러 차례 다시 처리할 수 있고, 단계 수와 batch, cache 활용, hardware 구현에 따라 비용이 달라진다.
따라서 diffusion이라는 이유만으로 같은 조건의 AR 시스템보다 항상 빠르다고 말할 수 없다.
양방향 문맥도 처음에는 대부분 mask일 수 있으므로 미래 token의 정답을 미리 알고 있다는 뜻은 아니다.

## 4. 확장과 남은 문제

Discrete diffusion은 mask 외에도 여러 token 사이의 전이 확률을 정할 수 있다.
연속 embedding에 noise를 더하는 접근은 상태를 token으로 읽어 내는 방법까지 함께 설계해야 한다.

전체 sequence를 한 번에 처리하는 접근 외에 block을 순차적으로 진행하면서 각 block 내부에서 diffusion을 사용하는 방식도 있다.
또한 처음부터 diffusion 모델을 학습하는 LLaDA와 달리 AR 모델의 weight에서 출발하는 Dream 같은 접근도 제안되었다.[^dream]
어떤 모델이 좋은지는 품질뿐 아니라 학습 비용, 생성 길이, 지연 시간, 처리량, infilling 등 task를 함께 고려해 비교해야 한다.

이미지와 언어의 공통점은 데이터를 점차 손상시키고 그 역방향 생성 과정을 학습한다는 발상이다.
공간이 연속인지 이산인지에 따라 noise, 모델 출력과 sampler의 구체적인 정의는 달라진다.
