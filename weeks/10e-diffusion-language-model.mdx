문장 가운데 두 단어가 비어 있다면 왼쪽과 오른쪽 문맥이 모두 단서가 된다.
Masked diffusion 언어 모델은 여러 자리가 가려진 문장을 복원하는 법을 배우고, 생성할 때는 먼저 채운 token을 단서로 남은 자리를 다시 예측한다.[^survey]
단어의 embedding에 연속적인 noise를 더하는 방법도 있다.
어느 표현을 손상시키느냐에 따라 모델이 한 단계에서 예측할 대상이 달라진다.

## 1. 텍스트의 생성과 손상

### 1-1. Autoregressive 생성

길이 $L$인 token sequence의 $i$번째 token을 $x^i$라 하자.
Autoregressive(AR) 모델은 앞서 나온 token을 바탕으로 다음 token을 예측한다.
전체 문장의 결합확률은 다음과 같이 분해된다.

$$
p(x^1,\ldots,x^L)=\prod_{i=1}^{L}p(x^i\mid x^1,\ldots,x^{i-1}).
$$

생성할 때 AR 모델은 첫 token을 뽑고, 그 결과를 조건으로 두 번째 token을 뽑는다.
이런 순차 decoding에서는 앞 token이 정해지기 전에 다음 token을 확정할 수 없다.
반면 학습할 때는 정답 sequence를 이미 알고 있으므로, 모델은 causal attention으로 여러 위치의 예측을 병렬로 계산할 수 있다.

### 1-2. Continuous와 discrete 상태

Diffusion에서 continuous와 discrete는 우선 모델이 손상시키는 **상태의 종류**를 말한다.
이미지 DDPM은 실수 벡터에 Gaussian noise를 더하므로 continuous-state diffusion이다.
시간을 여러 개의 정수 단계로 나눴더라도 상태의 값은 연속이다.
반면 discrete-state diffusion은 가능한 상태와 그 상태 사이의 전이 확률을 정의한다.[^d3pm]

텍스트에서도 두 접근이 모두 가능하다.[^diffusion-lm][^d3pm]

| 구분 | Continuous-state 언어 diffusion | Discrete-state 언어 diffusion |
|---|---|---|
| 모델이 다루는 상태 | token의 연속 embedding 벡터 | token이나 mask 같은 이산 기호 |
| Forward 손상 | 예를 들어 벡터에 Gaussian noise 추가 | 예를 들어 token을 mask로 대체 |
| 생성 결과 | 연속 벡터를 token으로 변환 | token 확률을 예측해 기호를 선택 |
| 예 | Diffusion-LM | D3PM, LLaDA |

Continuous 접근에서 `고양이` token을 embedding 벡터로 바꾼 뒤 벡터에 noise를 더하면, 중간 상태는 어느 단어 하나의 ID가 아니라 실수 벡터다.
Diffusion-LM은 우선 각 token의 학습 가능한 embedding을 중심으로 작은 Gaussian noise를 더해 연속 시작 상태 $x_0$를 뽑는다.
그다음 $x_0$에 단계별 noise를 섞는다.
모델은 손상된 벡터에서 $x_0$를 추정하도록 학습한다.[^diffusion-lm]
생성할 때 모델은 연속 noise 벡터에서 출발해 벡터를 반복해서 갱신한다.
마지막에는 그 벡터들을 어휘의 기호로 바꾸는 decoding 단계가 필요하다.
예를 들어 Diffusion-LM은 각 위치의 최종 벡터에서 token 확률을 계산하고 가장 확률이 높은 token을 선택하는 rounding을 사용한다.[^diffusion-lm]
확률이 비슷한 두 후보의 경계에서는 벡터의 작은 변화가 다른 token 선택으로 이어질 수도 있다.
이 변환을 어떻게 학습하고 처리할지가 continuous 접근의 별도 설계 문제다.

### 1-3. Mask를 이용한 이산 손상

Discrete 접근은 token ID 숫자에 noise를 더하지 않는다.
대신 한 기호가 다른 상태로 바뀔 확률을 정하고, mask는 그렇게 정할 수 있는 손상 방식 중 하나다.

예를 들어 원래 문장이 `나는 오늘 학교에 간다`라고 하자.
Forward 과정에서 둘째와 넷째 token을 가리면 `나는 [MASK] 학교에 [MASK]`가 되고, 끝까지 가리면 네 자리 모두 `[MASK]`가 된다.
[스탠퍼드 CME 295의 손상·복원 그림](https://cme295.stanford.edu/slides/fall25-cme295-lecture9.pdf#page=92)에서 위쪽 화살표는 원문에서 모든 자리가 가려질 때까지, 아래쪽 화살표는 가려진 다섯 자리에서 문장이 만들어질 때까지를 보여 준다.

실제 token은 단어나 띄어쓰기 단위와 일치하지 않을 수 있지만, 여기서는 어절 하나를 token 하나처럼 다룬다.
한 번 mask가 된 위치가 계속 mask로 남는 과정을 absorbing-mask 과정이라 한다.
손상 확률은 시간에 따라 정해진다.
생성 과정은 충분히 손상된 상태에서 출발해 역방향으로 token을 복원하도록 설계한다.

전이 확률을 행렬로 쓰면 mask 외의 손상 방식도 같은 틀에서 나타낼 수 있다.
가능한 상태를 `A`, `B`, `M` 세 가지로 줄이고, 행은 이전 상태, 열은 다음 상태라고 하자.

$$
Q=\begin{pmatrix}
0.8&0&0.2\\
0&0.8&0.2\\
0&0&1
\end{pmatrix}.
$$

첫 행은 `A`가 `A`에 머물 확률 0.8과 `M`으로 바뀔 확률 0.2를 나타낸다.
마지막 행에서는 mask가 mask로 남을 확률이 1이다.
같은 $Q$를 두 단계 연속 쓰면 처음 `A`였던 위치가 여전히 `A`일 확률은 $0.8^2=0.64$다.
서로 다른 단계의 전이 행렬을 곱하면 그 단계들을 거친 누적 전이를 얻는다.
D3PM은 이처럼 전이 행렬을 설계해 mask뿐 아니라 균등한 무작위 치환 같은 다른 이산 손상도 표현한다.[^d3pm]
그리고 텍스트 실험에서는 여러 전이 가운데 absorbing mask가 가장 좋은 결과를 냈다.

## 2. Masked diffusion의 학습과 생성

### 2-1. 학습 목표

D3PM은 이산 단계마다 역방향 전이 확률을 학습한다.
원논문은 단계별 역분포를 맞추는 변분 목적함수에 원래 token을 직접 예측하는 보조 cross-entropy 손실을 더했다.[^d3pm]
손상을 absorbing mask로 한정하면 학습 목표가 단순해진다.
가리는 비율을 바꿔 가며 가려진 위치의 정답 token을 예측하고, 비율별 예측 오차에 가중치를 주어 합친다.[^mdlm]

LLaDA는 이 방법으로 대규모 언어 모델을 학습했다.[^llada]
8B Transformer를 2.3조 token으로 처음부터 학습한 것이다.
사전학습에서 LLaDA는 $t$를 0과 1 사이에서 균일하게 뽑고, 각 token을 독립적으로 확률 $t$로 mask한다.
원래 sequence를 $x_0$, 손상된 sequence를 $x_t$, mask token을 $\mathrm{M}$이라 하면 손실은 다음과 같다.

$$
L(\theta)=\mathbb{E}_{t,x_0,x_t}\!\left[
-\frac{1}{t}\sum_{i=1}^{L}
\mathbf{1}[x_t^i=\mathrm{M}]\log p_\theta(x_0^i\mid x_t)
\right].
$$

지시 함수 $\mathbf{1}[\cdot]$는 해당 위치가 mask이면 1, 아니면 0이다.
그래서 손실은 가려진 위치에서만 계산된다.
모델은 남아 있는 양쪽 문맥을 보고, 가려진 위치마다 정답 token의 확률을 높이도록 학습한다.

[그림 원문](https://arxiv.org/html/2406.07524v2) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

$1/t$는 noise 수준에 따라 손실에 주는 가중치다.
$t$는 각 token이 mask될 확률이자 mask 비율의 기댓값이다.
가령 길이가 100인 sequence에서 $t=0.1$이면 평균 10개, $t=0.5$이면 평균 50개 위치가 가려진다.
각 위치의 손실이 1이라고 가정하면 가려진 위치의 손실 합의 기댓값은 각각 10과 50이고, $1/t$를 곱한 기댓값은 둘 다 100이다.
즉 $t$가 작으면 손실에 참여하는 위치가 적어지는 만큼 가중치가 커진다.
가령 $t=0.5$이고 가려진 두 위치의 정답 token 확률이 각각 0.8과 0.25라면, 자연로그를 쓰는 이 한 표본의 손실은 $-2(\log 0.8+\log 0.25)\approx3.22$다.
이 값은 두 위치의 log probability를 합한 다음 $1/t=2$를 곱한 것이다.

MDLM, MD4, RADD는 이 꼴의 목적함수가 데이터의 평균 negative log-likelihood(NLL), 즉 $-\mathbb{E}_{x_0\sim p_{\mathrm{data}}}[\log p_\theta(x_0)]$의 상한임을 보였다.[^md4][^mdlm][^radd]
여기서 $p_\theta$는 모델이 정의한 확률적 역전이를 따라 생성했을 때의 분포다.
NLL이 작을수록 모델이 실제 데이터에 높은 확률을 주므로, 이 상한을 낮추는 학습은 근사적인 maximum likelihood 학습이 된다.
일반식에서 가중치는 masking schedule에 따라 정해지고, mask 확률이 $t$와 같은 LLaDA의 선형 schedule에서 $1/t$가 된다.[^md4]
RADD는 또 mask된 위치에서 맞혀야 할 분포가 시간과 무관한, 깨끗한 데이터의 조건부 분포임을 보였다.[^radd]
그래서 LLaDA는 모델에 $t$를 따로 입력하지 않는다.

BERT도 가려진 자리의 원래 token을 맞히도록 학습한다.
다만 원논문은 입력 위치의 15%만 예측 대상으로 골라 그중 일부를 실제 `[MASK]`로 바꿨다.[^bert]
그래서 BERT는 대부분의 자리가 가려진 입력을 학습 중에 보지 않는다.
LLaDA는 거의 다 보이는 문장부터 거의 다 가려진 문장까지 학습한다.
그래서 생성할 때는 응답을 전부 가린 채 시작하고, 일부가 채워진 뒤에도 같은 예측기로 나머지 자리를 복원한다.

### 2-2. 신뢰도 기반 생성

Prompt는 조건으로 그대로 두고, 생성할 영역은 모두 mask로 채워 시작한다고 하자.
모델은 한 번 호출될 때 mask된 여러 위치의 후보 token 분포를 한꺼번에 낸다.
Sampler는 그 예측과 정해진 정책에 따라 일부 위치를 채우고, 남은 mask에 대해 다시 모델을 호출한다.

| 단계 | 생성 영역의 예시 |
|---|---|
| 시작 | `[MASK] [MASK] [MASK] [MASK]` |
| 중간 | `나는 [MASK] 학교에 [MASK]` |
| 종료 | `나는 오늘 학교에 간다` |

예를 들어 첫 호출에서 네 위치의 최고 확률 후보가 차례로 `나는` 0.90, `오늘` 0.55, `학교에` 0.80, `간다` 0.45라고 하자.
Sampler가 최고 후보의 확률을 신뢰도로 삼아 한 번에 두 위치를 채운다고 하자.
그러면 sampler는 신뢰도가 0.90과 0.80인 첫째와 셋째 위치를 채워 표의 중간 상태를 만든다.
다음 호출에서 모델은 `나는 [MASK] 학교에 [MASK]`라는 바뀐 문맥을 보고 남은 위치의 후보를 다시 계산한다.
그 결과가 `오늘` 0.85, `간다` 0.75라면 sampler는 두 위치를 채워 문장을 완성한다.
이 숫자는 작동을 설명하기 위한 가상 값이다.
이 예의 sampler는 먼저 채운 token을 그대로 유지한다.
채우는 순서도 왼쪽부터가 아니라 신뢰도 순서다.

이 예처럼 두 자리를 채울 때, 꼭 신뢰도가 높은 두 곳부터 골라야 할까?
선형 masking schedule의 역과정에서 위치를 고르는 확률은 모델의 신뢰도와 무관하다.[^llada]
생성 방향으로 시간 $t$에서 $r$로 이동한다고 하자($0\le r<t$).
Forward 과정에서는 한 번 가린 위치가 계속 가려지므로, 더 이른 시간 $r$에 이미 가려진 위치는 모두 $t$에도 가려져 있다.
한 위치가 두 시간 모두 가려질 확률은 $r$이고, $t$에 가려질 확률은 $t$다.
따라서 현재 가려진 위치가 $r$에서도 mask로 남을 조건부 확률은 $r/t$이고, 열릴 확률은 $1-r/t$다.

예를 들어 $t=1$에서 $r=0.5$로 이동하면 네 위치 각각이 열릴 확률은 절반이다.
평균적으로 두 곳이 열리지만, 한 번의 표본에서는 열리는 개수와 위치가 달라질 수 있다.
열리는 위치를 고른 뒤에는 모델의 예측 분포에서 그 자리에 놓을 token을 뽑는다.
LLaDA의 low-confidence remasking은 이 무작위 위치 선택을 바꾼다.
방금 예측한 후보 중 신뢰도가 높은 위치를 채우고 낮은 위치를 mask로 남긴다.[^llada]
저자들은 이 방법이 AR 모델에서 흔히 쓰는 annealed sampling처럼 생성 문장의 다양성을 줄여 정확도를 높인다는 가설을 제시했다.[^llada]
이렇게 정책을 바꾼 sampler의 분포는 앞의 NLL 상한이 다루는 분포와 다르다.

### 2-3. Instruction 학습과 응답 길이

Instruction을 따르는 모델은 prompt를 조건으로 두고 응답만 생성해야 한다.
LLaDA의 supervised fine-tuning(SFT)은 prompt를 그대로 보존하고 응답 부분의 token만 pre-training과 같은 방식으로 mask한다.[^llada]
Mini-batch 안에서 짧은 응답 뒤에는 EOS(end of sequence) token을 덧붙여 길이를 맞추고, 모델은 EOS도 일반 token처럼 예측하도록 학습한다.

LLaDA의 기본 diffusion sampler는 미리 지정한 응답 길이만큼 mask를 놓고 시작한다.
생성이 끝나면 EOS 뒤의 token은 버린다.
원논문의 주 평가는 Base 모델과 Instruct 모델 모두 이 방식으로, 응답 전체에서 신뢰도가 높은 위치부터 채웠다.[^llada]
이 설정에는 두 가지 문제가 있다.
응답이 짧아도 sampler는 매 단계 정해 둔 길이 전체를 다시 처리한다.
또 SFT 데이터에는 길이를 맞추려고 넣은 EOS가 많아서, Instruct 모델은 응답을 지나치게 일찍 끝내기 쉽다.

원논문은 sampling 전략을 비교하면서 응답을 32개 token짜리 block으로 나누는 방식도 평가했다.
이 sampler는 왼쪽 block부터 처리하고, 현재 block 안에서는 신뢰도가 높은 위치를 먼저 채운다.
Instruct 모델의 GSM8K 정확도는 응답 전체를 한 번에 채울 때 69.4, block으로 나눌 때 78.6이었고, 저자들은 EOS padding에 따른 조기 종료를 그 차이의 원인으로 들었다.[^llada]
Block 단위로 생성하는 sampler는 EOS가 나오면 종료할 수도 있다.

### 2-4. 가변 길이 생성

Improved LLaDA(iLLaDA)는 짧은 block을 덧붙여 생성하고, SFT에서 문장의 끝을 학습하는 방식도 바꿨다.[^illada]
각 instruction 예제를 prompt, 응답, EOS 하나의 순서로 잇고, 이렇게 이은 corpus에서 잘라 낸 학습 sequence 전체에 pre-training과 같은 masking을 적용한다.
그래서 prompt와 응답, EOS가 모두 학습 중에 가려질 수 있다.

생성할 때 iLLaDA는 prompt 뒤에 일정 크기의 mask block을 붙이고, 여러 denoising 단계에 걸쳐 신뢰도가 높은 예측을 채운다.
Block의 복원이 끝났을 때 EOS나 다른 stop token이 있으면 iLLaDA는 생성을 멈춘다.
없으면 새 mask block을 붙이고, 정해 둔 최대 생성 길이에 도달하면 멈춘다.
Block 안의 token은 병렬로 예측할 수 있지만 block 사이와 denoising 단계는 순차적으로 진행된다.

<Callout type="example">
Prompt가 `오늘 날씨는`이고 block 길이가 4라고 하자.
첫 입력은 prompt 뒤에 `[MASK] [MASK] [MASK] [MASK]`를 붙인 것이다.
모델이 네 위치의 후보를 한 번에 예측한 뒤, sampler가 자신 있는 위치부터 채우고 나머지를 다시 예측한다.
첫 block이 `맑고 바람이 약합니다 .`처럼 채워졌는데 EOS가 없다고 하자.
그러면 sampler는 이 block을 문맥으로 남기고 뒤에 새 mask block을 붙인다.
다음 block의 복원이 끝났을 때 EOS가 있으면, sampler는 생성을 멈춘다.
응답이 짧으면 block 몇 개로 끝나므로, 긴 고정 길이를 매 단계 처리할 필요가 없다.
</Callout>

## 3. AR 모델과의 비교

| 관점 | Autoregressive 모델 | Masked diffusion 언어 모델의 대표적 방식 |
|---|---|---|
| 학습 | 앞 문맥에서 다음 token 예측 | 다양한 손상 수준에서 가려진 token 예측 |
| 생성 | 앞에서 뒤로 token을 차례로 선택 | mask된 여러 위치를 반복적으로 예측하고 채움 |
| 문맥 | 생성 시 이미 나온 앞쪽 문맥 | 현재 남아 있거나 복원된 양쪽 문맥 |
| 계산 | token 생성마다 모델 호출 | 여러 token을 병렬 예측하되 여러 denoising 단계 필요 |
| 활용 | 자연스러운 왼쪽에서 오른쪽 이어 쓰기 | infilling과 유연한 위치 선택 가능 |

병렬로 여러 위치를 예측할 수 있다는 점은 잠재적 이점이다.
하지만 모델은 denoising 단계마다 전체 sequence를 다시 처리한다.
AR 모델은 앞 token의 key와 value를 KV cache(key-value cache)에 저장해 두고 다음 token을 만들 때 재사용한다.
LLaDA 원논문은 LLaDA가 KV cache와 호환되지 않는다고 밝힌다.[^llada]
양방향 attention에서는 새 token이 채워질 때마다 이미 계산한 다른 위치의 key와 value도 바뀔 수 있기 때문이다.
이후 KV cache와 비슷한 재사용 방식을 diffusion 언어 모델에 맞게 고친 방법들이 제안되었다.[^dkv]
그래서 실제 속도는 denoising 단계 수, batch 크기, cache 활용, hardware 구현에 따라 AR 모델보다 빠를 수도 느릴 수도 있다.
LLaDA 원논문의 측정에서 추론 최적화를 쓰지 않은 LLaDA 8B Base는 GSM8K와 Math에서 KV cache를 쓴 LLaMA3 8B Base와 비슷한 성능을 내면서 처리량이 각각 1.5배와 1.8배였다.
MBPP에서는 LLaMA3 쪽이 앞섰다.[^llada]

두 방식을 잇는 길도 있다.
처음부터 diffusion 모델을 학습하는 LLaDA와 달리, Dream은 사전학습한 AR 모델의 가중치에서 출발해 diffusion 언어 모델로 바꾼다.[^dream]
어떤 방식이 나은지는 품질뿐 아니라 학습 비용, 생성 길이, 지연 시간, 처리량, infilling 같은 task를 함께 놓고 비교해야 한다.
