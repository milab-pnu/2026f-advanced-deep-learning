이번 주는 3D를 어떤 표현으로 나타낼지 고르고(3D 표현), 사진으로 장면을 복원하며(NeRF → Gaussian Splatting), 생성 모델로 만들어 내는(3D generation) 계보를 다룬다.
계보의 출발 문제는 3D에는 이미지의 픽셀 격자처럼 하나로 정해진 표현이 없고, 3D 데이터가 2D보다 훨씬 적다는 것이다.

## 1. 3D 표현의 선택

- 이미지는 픽셀 격자 하나로 정해지지만, 3D는 무엇을 저장하느냐에 따라 표현이 갈린다
- 표현 비교 표: mesh, point cloud, voxel, neural implicit(SDF, occupancy), radiance field(NeRF), 3D Gaussian
  - 열: 저장하는 것, 메모리, 표면·topology, 렌더링, 편집, 주로 쓰이는 곳

## 2. Explicit 표현

- Mesh: 꼭짓점과 면. 그래픽스와 물리 시뮬레이션의 표준이고 생성 결과의 최종 형식이지만, 신경망으로 topology를 바꾸기 어렵다
- Voxel: 3D 격자. Convolution을 그대로 쓸 수 있지만, 해상도를 높이면 메모리가 세제곱으로 는다. 빈 공간을 저장하지 않는 sparse voxel로 줄인다
- Point cloud: 3D 점의 집합. LiDAR와 depth 카메라가 직접 내놓는 형식이다. 점 사이에 순서와 연결이 없어 표면이 없고, 신경망은 순서에 영향을 받지 않는 구조(PointNet, Point Transformer)를 쓴다

## 3. Neural implicit representation

- 좌표를 넣으면 값을 내는 신경망으로 형상을 표현한다
- SDF(표면까지의 부호 있는 거리)와 occupancy(안팎 확률)를 MLP로 표현하는 방식(DeepSDF, Occupancy Networks 계열)
- 장점: 해상도에 묶이지 않는 연속 표현, 매끄러운 표면, topology가 자유롭다
- 한계: 값을 얻으려면 매번 신경망을 계산해야 해 느리다
- Hybrid 표현: 격자나 평면(triplane, hash grid)에 feature를 저장하고 작은 MLP로 읽어 속도를 높인다
- 형상 대신 밀도와 색을 내게 하면 NeRF(radiance field)가 된다

## 4. 표현 사이의 변환

- 게임과 시뮬레이션은 mesh를 쓰므로, 다른 표현으로 만든 결과도 결국 mesh로 바꿔야 한다
- Implicit에서 mesh로: marching cubes
- Point cloud에서 mesh로: 표면 복원(surface reconstruction)
- 변환에서 잃는 것: 세부, topology 오류, texture
