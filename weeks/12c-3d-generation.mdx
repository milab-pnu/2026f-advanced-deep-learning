## 1. 3D 데이터의 부족

- 이미지·텍스트 쌍은 수십억 개지만, 3D 자산은 훨씬 적고 품질도 고르지 않다
- 그래서 3D 생성은 2D 생성 모델의 지식을 빌리는 방법에서 출발했다

## 2. Score distillation

- 3D 표현(NeRF나 Gaussian)을 여러 시점에서 렌더링하고, 2D diffusion 모델이 그 이미지를 그럴듯하게 여기는 방향으로 3D 표현을 최적화한다(DreamFusion)
- 3D 데이터 없이 텍스트만으로 3D를 만든다
- 한계: 물체마다 긴 최적화, 큰 CFG scale로 인한 과포화, 시점마다 앞면이 생기는 문제

## 3. Multi-view diffusion

- 문제: 2D 모델은 시점 사이의 일관성을 모른다
- 2D diffusion 모델에 카메라 조건을 넣어 다른 시점의 이미지를 생성하게 한다(Zero-1-to-3)
- 여러 시점을 한 번에 생성한다. 비디오 생성 모델을 여러 시점 생성기로 쓰기도 한다(SV3D, CAT3D)
- 생성한 여러 시점 이미지는 NeRF나 Gaussian Splatting으로 복원한다

## 4. Feed-forward 복원

- 문제: 물체마다 최적화하면 느리다
- 이미지 한 장이나 몇 장에서 3D 표현을 한 번의 추론으로 예측한다
- LRM: 이미지 한 장에서 radiance field를 바로 예측하는 대형 Transformer

## 5. 3D latent에서의 생성

- 이미지의 latent diffusion과 같은 두 단계: 3D 형상을 latent로 압축하는 autoencoder를 학습하고, 그 latent에서 생성 모델을 학습한다
- TRELLIS: 구조화된 3D latent 하나에서 radiance field, 3D Gaussian, mesh를 모두 decoding한다
- Hunyuan3D 2.0: flow 기반 DiT로 형상을 만들고, 별도 모델로 texture를 입힌다
- 이미지·비디오 생성의 flow matching과 DiT가 3D latent에도 그대로 쓰인다

## 6. 평가와 남은 문제

- 3D 생성은 정답이 없어 평가가 어렵다: 렌더링한 이미지의 품질과 텍스트 일치, 사람 평가
- 남은 문제: texture와 topology의 품질, 물체를 넘어 장면 전체의 생성
- 정리 표: 방식, 3D 데이터 필요 여부, 생성 시간, 출력 표현
