고해상도 이미지에 diffusion을 적용하면 매 단계에서 큰 이미지 배열을 신경망으로 처리해야 한다.
Latent diffusion은 먼저 이미지를 압축한 표현에서 반복적인 denoising을 수행해 이 비용을 줄인다.[^survey]
Stable Diffusion의 초기 text-to-image 모델을 기준으로 autoencoder, text encoder, U-Net이 학습과 생성에서 어떻게 연결되는지 살펴본다.[^ldm]
이 구조를 바탕으로 기존 이미지에 noise를 더해 편집하는 방법과, 원본 이미지와 편집 지시를 조건으로 학습하는 InstructPix2Pix도 살펴본다.

## 1. Pixel에서 latent로

### 1-1. 압축 표현

$512\times512$ RGB 이미지는 색 채널을 포함해 786,432개의 값을 가진다.
이 공간에서 수십 번 denoising하면 매번 큰 공간 배열을 처리해야 한다.
Latent diffusion은 encoder $E$로 이미지를 더 작은 latent $z_0=E(x)$로 바꾸고 decoder $D$가 latent에서 이미지를 복원하도록 학습한다.
이 autoencoder는 이미지의 중요한 구조를 남기면서 공간 해상도를 줄인다.

<Callout type="example">
초기 Stable Diffusion 계열에서 흔히 사용하는 예로 $512\times512\times3$ 이미지를 $64\times64\times4$ latent로 바꾸면 배열 원소 수가 786,432개에서 16,384개로 줄어든다.
원소 수가 48분의 1이라고 해서 전체 실행 시간이 정확히 48분의 1이 되는 것은 아니다.
신경망의 채널 수, attention, 구현과 decoder 비용이 함께 영향을 준다.
</Callout>

압축에는 대가가 있다.
Decoder가 잃어버린 세부 정보를 완벽하게 복원할 수 없다면 diffusion 모델이 latent를 잘 만들어도 최종 이미지의 세부 표현에 한계가 생긴다.
$D(E(x))$는 일반적으로 원본 $x$와 정확히 같지 않다.
Latent는 사람이 해석하기 쉬운 개별 개념의 목록이 아니라 이미지 정보를 담도록 학습한 연속 배열이다.

### 1-2. 두 단계 학습

Latent diffusion은 먼저 이미지 autoencoder를 학습하고, 그 encoder가 만든 latent를 대상으로 diffusion model을 학습한다.[^ldm]
Autoencoder의 학습에는 복원 품질과 latent 공간의 성질을 조절하는 항들이 사용된다.
구체적인 정규화 방식은 모델마다 다르며, 모든 autoencoder가 같은 VAE 구조인 것은 아니다.
Diffusion을 학습할 때는 학습된 encoder로 이미지 $x$를 $z_0$로 바꾸고, 임의의 시간과 noise를 뽑아 $z_t$를 만든다.
Text 조건 $c$가 있는 noise 예측 손실은 다음과 같이 쓴다.

$$
L=\mathbb{E}_{z_0,c,t,\epsilon}\left[\left\|\epsilon-\epsilon_\theta(z_t,t,c)\right\|^2\right],
\qquad z_t=\sqrt{\bar\alpha_t}z_0+\sqrt{1-\bar\alpha_t}\epsilon.
$$

여기서 $\epsilon$은 표준 Gaussian noise이고 $\bar\alpha_t$는 단계 $t$에서 원본 신호가 남는 정도를 정하는 계수다.
식의 형태는 pixel 공간의 denoising diffusion probabilistic model(DDPM)과 같지만 데이터가 $x_0$ 대신 $z_0$라는 점이 다르다.
Encoder와 decoder는 반복 denoising의 대체물이 아니다.
Encoder는 학습 이미지를 latent로 바꾸고, denoiser는 latent 분포를 배우며, decoder는 생성된 latent를 이미지로 바꾼다.

## 2. U-Net과 텍스트 조건

### 2-1. U-Net의 공간 처리

초기 Stable Diffusion의 denoiser는 U-Net 계열이다.
U-Net은 입력에서 시작해 공간 해상도를 단계적으로 낮추며 특징을 추출하고, 가운데를 통과한 다음 해상도를 다시 높인다.
낮은 해상도에서는 더 넓은 영역의 정보를 결합하기 쉽고, 높은 해상도에서는 공간적 세부 정보를 유지하기 쉽다.
Downsampling 경로에서 얻은 특징을 같은 해상도의 upsampling 경로로 넘기는 skip connection은 복원 단계에 세부 정보를 전달한다.[^unet]

다음은 구조를 이해하기 위한 **가상의 간소화된 예**다.
실제 Stable Diffusion의 block 수와 channel 수를 그대로 나타낸 것은 아니다.
높이와 너비를 줄일 때는 공간 정보를 압축하고, decoder 경로에서는 같은 크기의 skip 특징과 합쳐 위치별 정보를 다시 활용한다.

| 처리 | 특징의 공간 크기 | 전달하는 정보 |
|---|---|---|
| 입력 | $64\times64$ noisy latent | 현재 noise가 섞인 이미지 표현 |
| Down 경로 | $64\times64\to32\times32\to16\times16$ | 각 크기의 특징을 skip 경로에 저장 |
| 가운데 | $16\times16$ | 더 넓은 영역의 문맥 처리 |
| Up 경로 | $16\times16\to32\times32\to64\times64$ | 같은 크기의 down 특징을 결합 |
| 출력 | $64\times64$ | 각 latent 위치의 noise 예측 |

예를 들어 up 경로의 $32\times32$ 특징이 channel 128개이고, 저장한 skip 특징이 channel 64개라고 하자.
Channel 방향으로 이어 붙이는 구현에서는 $32\times32\times192$ 배열이 된다.
그다음 block이 이 특징을 변환한다.
공간 크기가 같아야 대응 위치를 결합할 수 있으며, skip이 전달하는 것은 깨끗한 정답 이미지가 아니라 **현재 noisy 입력에서 계산한 중간 특징**이다.

이 U-Net은 segmentation을 위해 처음 제안된 U-Net을 그대로 사용하는 것은 아니다.
Diffusion에 맞춰 noisy latent와 timestep을 입력으로 받고 residual block, attention과 conditioning을 결합해 noise를 예측하도록 구성한다.
시간 embedding은 현재 noise 수준을 각 처리 단계에 알려 준다.
같은 형태의 $z_t$라도 $t$가 다르면 섞인 noise의 정도가 다르므로 이를 구별해야 한다.

### 2-2. Text encoder와 cross-attention

“빨간 우산을 든 사람”이라는 prompt는 text encoder를 통해 token별 문맥 벡터로 바뀐다.
Cross-attention은 U-Net의 이미지 특징에서 query $Q$를, 텍스트 표현에서 key $K$와 value $V$를 만들어 다음과 같이 계산한다.

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
$$

$d_k$는 query와 key 벡터의 차원이며, 제곱근으로 나누어 내적의 크기를 조절한다.
이미지 쪽 각 위치의 query가 텍스트 token들과의 관련성을 계산해 텍스트 정보를 받아온다.
이로써 서로 다른 이미지 위치가 prompt의 서로 다른 부분을 참고할 수 있다.
초기 Stable Diffusion에서는 CLIP 계열 text encoder를 사용한다.
CLIP은 이미지와 그에 맞는 텍스트 표현을 가깝게 만드는 contrastive 학습으로 이미지와 언어의 관계를 익힌다.[^clip]
그중 text encoder의 출력을 이미지 생성의 조건으로 사용하며, CLIP의 정렬 학습과 diffusion 모델의 noise 예측 학습은 서로 다르다.[^sd]
Text encoder의 종류와 학습 여부는 버전마다 확인해야 한다.

## 3. 생성의 전체 경로

학습 시에는 실제 이미지와 그에 대응하는 텍스트가 필요하다.
생성 시에는 실제 이미지 대신 Gaussian latent noise에서 출발하고 prompt를 조건으로 준다.

| 단계 | 학습 | 생성 |
|---|---|---|
| 시작 | 실제 이미지를 encoder로 latent로 변환 | 임의의 latent noise 생성 |
| 조건 | 이미지에 대응하는 텍스트 인코딩 | 사용자의 prompt 인코딩 |
| denoising | 임의 단계에서 추가된 noise를 맞히도록 학습 | 예측과 sampler를 이용해 여러 단계 갱신 |
| 이미지 | autoencoder의 복원 학습에 사용 | 완성된 latent를 decoder로 변환 |

생성 중 U-Net은 매 단계 현재 latent, 시간, 텍스트 조건을 입력받는다.
Sampler가 이 예측으로 다음 latent를 만들고, 마지막 latent를 decoder가 pixel 공간의 이미지로 바꾼다.
Classifier-free guidance(CFG)를 쓰는 경우 조건부 예측과 조건을 제거한 예측을 결합해 sampler에 전달한다.
두 예측의 차이에 guidance scale을 곱해 조건의 영향을 조절한다.
결과 이미지는 prompt, 초기 noise, 학습된 모델, guidance scale과 sampler의 영향을 함께 받는다.

## 4. 기존 이미지의 편집

### 4-1. Image-to-image와 noise 수준

Text-to-image는 임의의 noise와 텍스트에서 새 이미지를 만든다.
반면 image-to-image에서는 기존 이미지의 구도나 내용을 남기면서 일부를 바꾸고 싶다.
한 가지 방법은 기존 이미지를 encoder로 latent $z_{\mathrm{in}}$으로 바꾸고, 선택한 단계 $t_0$에 해당하는 noise를 더한 다음 거기서부터 denoising하는 것이다.

$$
z_{t_0}=\sqrt{\bar\alpha_{t_0}}z_{\mathrm{in}}+\sqrt{1-\bar\alpha_{t_0}}\epsilon,
\qquad \epsilon\sim\mathcal{N}(0,I).
$$

이후 text 조건을 주면서 $z_{t_0}$에서 낮은 noise 단계로 이동하고, 마지막 latent를 decoder로 이미지로 바꾼다.
원본 정보가 남은 상태에서 시작하므로 완전히 새로운 noise에서 생성하는 경우보다 원본과 연결될 여지가 있다.
SDEdit은 입력에 noise를 넣은 뒤 학습된 diffusion prior로 denoising하는 접근을 제안했다.[^sdedit]
위 식은 같은 직관을 **latent DDPM의 표기**로 나타낸 것으로, SDEdit 원논문의 연속시간 SDE 식과 동일한 구현이라는 뜻은 아니다.

예를 들어 원본이 낮에 찍은 거리 사진이고 텍스트 조건이 “밤의 거리”라 하자.
Noise를 적게 넣으면 거리의 구도가 비교적 많이 남지만 밤으로 바뀌는 정도가 약할 수 있다.
더 많이 넣으면 바뀔 여지가 커지는 대신 건물의 위치나 모양까지 달라질 수 있다.
변화량은 noise 수준 외에도 prompt, 모델, sampler와 random seed에 영향을 받으며, 특정 영역의 보존이 보장되는 것은 아니다.

### 4-2. 편집 지시와 학습 데이터

“밤의 거리”는 결과 이미지의 설명이다.
“낮 사진을 밤으로 바꿔 줘”는 입력 이미지에 대해 수행할 **편집 지시**다.
InstructPix2Pix는 원본 이미지와 편집 지시를 함께 받아 편집 결과를 생성하도록 Stable Diffusion을 추가 학습한다.[^instructpix]
이를 위해서는 `(원본 이미지, 지시, 편집된 이미지)`가 함께 필요하다.
임의의 두 이미지만 모으면 지시와 대응되는 한 장면의 전후 관계를 알기 어렵다.

<Figure src="https://arxiv.org/html/2211.09800v2/method.png" alt="왼쪽은 GPT-3가 원본 설명으로 편집 지시와 변경된 설명을 만들고 Stable Diffusion과 Prompt-to-Prompt가 전후 이미지 쌍을 만드는 과정이다. 오른쪽은 입력 이미지와 지시를 InstructPix2Pix에 넣어 편집된 이미지를 얻는 예다." caption="왼쪽은 합성 학습 데이터 생성, 오른쪽은 학습된 모델의 편집 예시다. 데이터 생성에 쓴 GPT-3와 Prompt-to-Prompt를 사용자의 이미지마다 다시 실행하는 구조는 아니다." source="Brooks et al. (2023), Figure 2 · CC BY 4.0" wide />

그림은 [원논문](https://arxiv.org/abs/2211.09800)의 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 조건으로 제공된다.
연구진은 사람이 작성한 예시로 GPT-3를 fine-tuning하고, 이미지 설명에서 편집 지시와 편집 후 설명을 생성했다.
예를 들어 “말을 탄 사람”이라는 설명에서 “말을 용으로 바꿔 줘”라는 지시와 “용을 탄 사람”이라는 결과 설명을 만든다.
이 텍스트 예시는 이해를 위한 번역이다.

이어서 두 설명을 Stable Diffusion과 Prompt-to-Prompt에 넣어 편집 전후의 합성 이미지 쌍을 만든다.
Prompt-to-Prompt는 원래 cross-attention을 조절해 두 이미지가 공유할 내용이 유지되도록 돕는 방법이다.[^prompt2prompt]
InstructPix2Pix의 데이터 생성 구현은 이 아이디어를 변형해 두 이미지의 noise를 맞추고 일부 단계의 self-attention을 공유한다.[^instructpix]
연구진은 여러 후보를 만들고 CLIP 기반 점수로 이미지 간 유사성과 지시에 맞는 변화 등을 확인해 학습에 사용할 쌍을 고른다.
합성된 쌍에도 원치 않는 변화나 지시 불일치가 남을 수 있으므로 이 과정이 완벽한 정답을 보장하지는 않는다.

### 4-3. 원본 이미지와 지시를 조건으로 학습

원본 이미지를 $I$, 편집된 정답 이미지를 $Y$, 지시 텍스트를 $c$라 하자.
각 이미지를 같은 autoencoder의 encoder $E$로 latent $z_I=E(I)$와 $z_Y=E(Y)$로 바꾼다.
학습 시 noise를 더하는 대상은 **편집된 정답** $z_Y$다.
임의의 시간 $t$와 표준 Gaussian noise $\epsilon$을 뽑아 $z_t=\sqrt{\bar\alpha_t}z_Y+\sqrt{1-\bar\alpha_t}\epsilon$을 만든다.
모델은 $z_t$, 시간, 원본 latent $z_I$, 지시 $c$를 보고 추가한 noise를 예측한다.

$$
L=\mathbb{E}\left[\left\|\epsilon-\epsilon_\theta(z_t,t,z_I,c)\right\|^2\right].
$$

여기서 기대값은 학습 예제, 시간과 noise를 뽑는 경우들에 대한 평균이다.
원본 latent는 모델에 원래 장면을 알려 주는 조건이고, noisy latent는 모델이 생성해야 할 편집 결과의 현재 상태다.
원논문은 두 latent를 channel 방향으로 이어 U-Net의 첫 convolution 입력에 넣고, 지시는 text encoder와 cross-attention을 통해 전달한다.
예를 들어 두 latent가 각각 $64\times64\times4$이면 연결된 U-Net 입력은 $64\times64\times8$이다.
이는 입력 channel을 설명하는 예시이며, 원논문의 학습 이미지 해상도를 뜻하지 않는다.
기존 Stable Diffusion weight로 초기화하되, 새 이미지 조건 channel에 대응하는 weight는 0에서 시작한다.

### 4-4. 생성과 두 조건의 guidance

사용할 때는 편집 정답 $Y$를 모른다.
원본 이미지와 지시를 조건으로 두고 편집 결과의 latent는 Gaussian noise에서 시작한다.
U-Net의 예측과 sampler를 여러 번 적용한 뒤 마지막 latent를 decoder에 넣는다.
Image-to-image에서 원본 latent에 noise를 더해 생성의 출발점으로 삼은 것과 달리, 여기서는 원본 latent를 매 단계 별도의 조건으로 제공한다.
두 방법 모두 원본을 활용하지만, noise에서 복원할 대상과 원본을 전달하는 경로가 다르다.
한 사용자의 이미지에 맞춰 매번 모델을 다시 학습하거나, 입력 이미지를 noise로 역변환하는 inversion을 수행할 필요는 없지만, diffusion의 denoising 단계들은 반복된다.

InstructPix2Pix는 원본 이미지와 텍스트 지시의 영향을 따로 조절하기 위해 두 조건을 각각 또는 함께 제거한 예제도 학습한다.
생성 시에는 조건이 모두 없는 예측, 이미지만 있는 예측, 이미지와 지시가 모두 있는 예측을 결합한다.
이를 각각 $\epsilon_{\varnothing}$, $\epsilon_I$, $\epsilon_{I,c}$라 하면 원논문의 결합 방식은 다음과 같다.

$$
\hat\epsilon=\epsilon_{\varnothing}+s_I(\epsilon_I-\epsilon_{\varnothing})+s_T(\epsilon_{I,c}-\epsilon_I).
$$

$s_I$와 $s_T$가 둘 다 1이면 두 차이 항이 이어져 최종적으로 $\epsilon_{I,c}$가 된다.
셋은 같은 현재 latent와 시간에서 조건만 달리하여 얻은 예측이다.
이미지 guidance scale은 원본과의 유사성, 텍스트 guidance scale은 지시 반영 정도를 조절하는 데 쓰인다.
두 값이 결과에 미치는 영향은 서로 얽혀 있고, 어느 값을 키운다고 원하는 속성만 완벽히 보존하거나 변경한다는 보장은 없다.
ControlNet처럼 edge나 pose를 공간 조건으로 제공하는 방법은 제어할 정보를 보태는 다른 접근이다.
이런 조건부 생성에서 U-Net이 맡은 noise 예측을 Transformer로 구현해도 latent 공간에서 반복적으로 생성한다는 관점은 유지된다.
